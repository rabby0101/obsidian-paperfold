# Paperfold

An Obsidian theme by Sk Fazla Rabby, built on the default theme. Made to pair with [Homepage (Rabby)](https://github.com/rabby0101/obsidian-homepage) and [Task Manager (Rabby)](https://github.com/rabby0101/obsidian-task-manager).

## Install with BRAT

1. Install the BRAT community plugin.
2. BRAT → Add a beta theme → `rabby0101/obsidian-paperfold`.
3. Settings → Appearance → Themes → Paperfold.

Pick any accent colour under Appearance; the theme follows it.
